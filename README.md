# 🛍️ Customer Shopping Behaviour Analysis

## 📌 Project Overview

This project analyzes customer shopping behaviour to understand purchasing patterns, customer preferences, spending habits, product performance, and customer satisfaction.

The analysis was performed using **Python, SQL, and Power BI**, with an interactive dashboard created to present key business insights in a clear and professional way.

## 🎯 Objectives

- Analyze customer purchasing behaviour
- Identify high-performing product categories
- Understand customer spending patterns
- Analyze customer demographics and preferences
- Evaluate customer review ratings
- Identify trends that can help improve business decisions

## 🛠️ Tools & Technologies

- **Python** – Data cleaning and exploratory analysis
- **Pandas** – Data manipulation and analysis
- **SQL** – Data querying and business analysis
- **Power BI** – Interactive dashboard and visualization
- **DAX** – Calculated measures and KPIs

## 📊 Dashboard

The Power BI dashboard provides an interactive view of:

- 👥 Customer Count
- 💰 Average Purchase Amount
- ⭐ Average Review Rating
- 🛍️ Sales by Product Category
- 👤 Customer Demographics
- 📈 Customer Purchasing Patterns
- 🔄 Customer Behaviour Trends

## 🔍 Key Analysis

The project focuses on answering questions such as:

- Which product categories generate the most purchases?
- What is the average customer spending?
- Which customer groups are the most active?
- How do customers rate their purchases?
- What purchasing patterns can be identified?
- Which factors influence customer behaviour?
